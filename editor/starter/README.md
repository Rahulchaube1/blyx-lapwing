# Lapwing starter

Preflight fixed-line document pagination with indivisible paragraphs.

Open the extracted folder in VS Code. With Blyx 0.2.1 and its host toolchain installed, choose **Terminal → Run Task → Run Lapwing** or run the following command in this directory.

```sh
blyxc native-run main.blyx
```

Expected output

```text
2
3
7
10
```

The vendor directory contains the framework source for 0.1.0 and its license texts. [Read the API guide](https://www.blyx-lang.space/packages/lapwing) · [View the release](https://github.com/Rahulchaube1/blyx-lapwing/releases/tag/v0.1.0)
